# Code LLM 在企业级数据仓库中的应用

## 核心逻辑

大模型在数仓中的落地核心在于两大维度：
1. **数据确权**: 管理审批与技术实现的分离
2. **规范化输入输出**: 标准化数据接口和输出格式

## 提效场景

贯穿需求分析、ETL 开发、SQL 生成、数据测试、文档生成全流程。

> 数仓引入 Code LLM 不是简单的工具替换，而是对研发范式、职责边界及工具链架构的系统性升级 ^[inferred]
