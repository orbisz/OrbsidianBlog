# OpenAI 2025 开发者日

## 四项重大更新

### 1. Apps SDK
OpenAI 最大野心——将 ChatGPT 打造成未来的操作系统。在 ChatGPT 内直接调用其他 APP。

### 2. AgentKit
无需编码，拖放搭建智能体。三个核心工具：
- **Agent Builder**: 可视化画布 Connector
- **Registry**: 管理数据和工具连接
- **ChatKit**: 嵌入定制聊天界面的工具包

8 分钟拖拽即可完成完整 Agent 搭建 ^[inferred]

### 3. Codex 全面可用
零代码打造应用。

### 4. API 更新
Sora 2 API 同步上线。
